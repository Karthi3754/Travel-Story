# 🌍 Travel-Story

Travel-Story is a full-stack web application that allows users to share their travel experiences, upload photos on personally.

## 🚀 Features

- 📝 *User Authentication* – Sign up, login, and manage profiles.
- 📸 *Post Travel Stories* – Users can write stories, upload images, and share experiences.
- 💬 *Comments & Likes* – Engage with posts through comments and likes.
- 📍 *Location Tagging* – Attach locations to travel stories.
- 🔍 *Search & Filter* – Find travel stories by location, tags, or keywords.
- 📊 *Sort by Popularity* – Sort stories based on the number of likes.

## 🏗 Tech Stack

### Frontend:
- *Framework:* React
- *Styling:* Tailwind CSS

### Backend:
- *Runtime:* Node.js with Express.js
- *Database:* MongoDB (Mongoose)
- *Authentication:* JWT
- *Cloud Storage:* Local
